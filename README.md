# 🛡️ SC-500: Security for Cloud and AI Workloads (A Red Teamer's Guide)

Bienvenido a mi repositorio de estudio para la certificación **Microsoft SC-500 (Implementing End-to-End Security Controls for Cloud and AI Workloads)**. 

Como profesional de ciberseguridad ofensiva (Red Team), he creado este material con un objetivo claro: **para romper un sistema, primero tienes que entender exactamente cómo el Blue Team construye y configura sus defensas**. Aquí encontrarás la teoría destilada, laboratorios tácticos y un simulacro interactivo para dominar Entra ID, Defender CSPM, arquitecturas Zero Trust y la nueva frontera de la ciberseguridad: las cargas de trabajo de Inteligencia Artificial.

## 📂 Arquitectura del Repositorio

### 🗺️ [Roadmap de Estudio](./Roadmap_SC500.md)
Mi plan de asalto estructurado en 3 fases (Reconocimiento, Explotación y Exfiltración), con los enlaces a las listas de reproducción, laboratorios oficiales y el flujo de trabajo para atacar la certificación.

### 📚 [Apuntes Teóricos (27 Capítulos)](./Apuntes)
Resúmenes técnicos y directos al grano, divididos en los 4 dominios del examen:
*   **Dominio 1: Identidad y Acceso** - *Entra ID, PIM, Conditional Access, Key Vault.*
*   **Dominio 2: Gobernanza, Datos y Redes** - *Azure Policy, Storage, SQL, NSGs, Private Endpoints.*
*   **Dominio 3: Computación y Aplicaciones** - *Defender for Servers, AKS, App Service.*
*   **Dominio 4: Postura, Operaciones e IA** - *Defender CSPM, Microsoft Sentinel, AI Foundry, Security Copilot.*

### 🧪 [Laboratorios Prácticos (Hands-on)](./Labs)
Directorios preparados para documentar despliegues reales ("Diario de Campo"), segmentados por dominio. Contienen los *Challenges* de ataque y defensa:
*   `/Domain_1_Identity`
*   `/Domain_2_Data_and_Network`
*   `/Domain_3_Compute_and_Apps`
*   `/Domain_4_Posture_and_AI`

### 🧠 [Simulacro de Examen Interactivo](./Simulacro%20Examen)
Un examen de prueba completo para entrenar la gestión del tiempo y la lógica de Microsoft.
*   Contiene **86 preguntas reales** sobre casos de estudio y arquitecturas.
*   Las opciones de respuesta están **aleatorizadas**.
*   Formato sin *spoilers*: autoevalúate desplegando el botón **"💡 Ver Respuesta y Explicación"** al final de cada enunciado.
