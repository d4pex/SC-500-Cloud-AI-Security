Los NSGs (vistos en el capítulo 12) son excelentes para subredes, pero no pueden leer el interior de los paquetes de datos ni inspeccionar tráfico cifrado. Para eso, necesitas artillería pesada.

1.Las 3 Categorías de Azure Firewall
Azure Firewall es un servicio gestionado (no administras las VMs debajo de él). Tienes que saber elegir la versión (SKU) correcta para el examen:
* Basic: Para entornos pequeños o desarrollo. Max 250 Mbps. No tiene funciones avanzadas.
* Standard: El estándar para producción. Soporta inteligencia de amenazas (Threat Intelligence) y DNS Proxy.
* Premium: ¡La estrella del examen! Debes elegir esta opción siempre que el escenario te pida:
	* TLS Inspection (Inspección de tráfico cifrado HTTPS).
	* IDPS (Intrusion Detection and Prevention System / Detección de firmas de ataques).
	* URL Filtering o Web Category Filtering (Ej. Bloquear acceso a "Redes Sociales" o "Sitios de apuestas").

2.Jerarquía de Políticas de Firewall (Firewall Policies)
Ya no se configuran las reglas directamente en el firewall, sino en un recurso llamado Firewall Policy.
* Políticas Jerárquicas: Puedes tener una "Política Padre" (creada por el CISO/Seguridad Central) y "Políticas Hijo" (creadas por cada equipo de desarrollo).
* Regla de Oro (TRAMPA DE EXAMEN): Una política hijo NUNCA puede anular (override) a una política padre. Si el Padre dice "Denegar Puerto 22", el equipo de desarrollo no puede abrir el puerto 22, por mucho que ponga su regla en la prioridad número 1. Las reglas del padre siempre se evalúan primero.

3.El Orden de Evaluación de las Reglas
Dentro de un Firewall, las reglas se evalúan en este orden estricto:
* DNAT Rules (Inbound): Reglas de traducción de red (para publicar servicios al exterior).
* Network Rules (Capa 3 y 4): Filtrado por IP y Puerto (Ej. Bloquear la IP 8.8.8.8).
* Application Rules (Capa 7): Filtrado por nombre de dominio (FQDN), URLs y categorías web. (Requiere que el paquete pase las dos capas anteriores para llegar aquí).

4.Inspección TLS (TLS Inspection)
Exclusivo del Firewall Premium. El firewall actúa como un "intermediario autorizado" (Man-in-the-Middle).
* Descifra el tráfico de salida de tus VMs, lo inspecciona en busca de malware (IDPS), lo vuelve a cifrar y lo envía a Internet.
* Requisito técnico: Para que funcione, el Firewall necesita un certificado guardado en un Azure Key Vault y una Managed Identity para poder leerlo.

5.WAF (Web Application Firewall)
Azure Firewall protege la red general, pero WAF protege exclusivamente aplicaciones web (Capa 7) contra ataques comunes como Inyección SQL o Cross-Site Scripting (XSS).
* Se despliega adjunto a un Azure Front Door (para tráfico web global) o a un Application Gateway (para tráfico regional/interno).
* No reemplaza a Azure Firewall, trabajan juntos. WAF protege las webs entrantes, Firewall protege la red y el tráfico saliente.

6.VPN vs. ExpressRoute (El debate del cifrado)
Cuando conectas tu oficina (On-Premises) a Azure, tienes dos opciones principales:
* Site-to-Site VPN: Va por Internet. Es más lento y barato, pero está cifrado por defecto (túnel IPsec).
* ExpressRoute: Es un cable de fibra óptica privado directo desde tu oficina a Microsoft. Es rápido y caro, pero NO está cifrado por defecto (porque al ser privado, Microsoft asume que nadie lo puede pinchar).
* Escenario de examen: Si un cliente tiene requerimientos estrictos de cumplimiento (compliance) que exigen "cifrado extremo a extremo", y usan ExpressRoute, la respuesta es que debes configurar un túnel IPsec (VPN) por encima de ExpressRoute (Over-the-top encryption).

7.Azure Virtual WAN (vWAN) y Routing Intent
* Cuando tienes docenas de oficinas, VPNs y VNets, gestionar las rutas a mano (Route Tables / UDRs) es una pesadilla.
* Virtual WAN centraliza todo en un "Hub" gigante administrado por Microsoft.
* Routing Intent (Intención de enrutamiento): Es una función mágica de vWAN que te permite forzar automáticamente a que todo el tráfico (Internet, entre sucursales, o entre VNets) pase por el Azure Firewall central, sin tener que escribir ni una sola tabla de enrutamiento manualmente.
